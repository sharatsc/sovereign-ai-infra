# Sovereign AI reference infrastructure

Deployable reference implementations for the control profiles in the Sovereign AI
briefing. Each folder is one deployment variant on one cloud.

| Variant | Cloud | Template |
|---|---|---|
| Provider models in public cloud | Azure | [provider-models-public-cloud/azure](provider-models-public-cloud/azure/README.md) |

These templates contain no secrets. Credentials are created inside your subscription
at deploy time.
